# 常见问题

## 源码下载后不能直接运行

源码包不包含 Python 解释器和 EXE。请安装 64 位 Python 3.11/3.12 与 Edge，运行 `setup.cmd`；或者下载 Release 中的 Windows 运行包。

## 已登录但获取不到列表

确认使用程序打开的 Edge，进入「内容管理 → 发表记录」并清空筛选。查看版本是否为最新版，以及备份目录中的 `采集诊断.json`。提交问题时仅提供脱敏的字段结构和错误，勿附带 token 或 Cookie。

## 发表次数和文章篇数不同

一条发表记录可包含多篇文章。程序分别统计发表次数与去重后的文章条数。无详情记录会保留为异常行，不能推算已丢失的篇数。

## 已删除文章能恢复吗

不能保证。后台已删除或不再提供正文时，只保留已知标题、日期、链接及状态，不会生成虚假的正文。

## HTML 离线时图片能显示吗

成功下载的正文图片和背景图内嵌在 HTML。图片失败会显示部分完成并附带警告；再次开始可以重试。普通超链接仍需联网访问。

## 继续下载会重复保存吗

使用同一个下载目录，已完成的格式会校验 SHA-256。校验通过则跳过，损坏文件、缺少格式和失败项会重试。

## PDF 跟手机排版不完全一样

PDF 使用 A4 分页，字号、换行受本机字体与页面宽度影响。动态图、音视频与交互内容需要人工核对。

## Excel 导出失败

关闭正在占用 `文章目录.xlsx` 的 Excel / WPS，再点击导出目录与报告。JSON 中的下载进度仍然保留。

## 能否备份别人的公众号全部历史

本工具面向已登录且有管理权限的自有公众号后台，不提供跨账号历史发现或绕过访问控制功能。
